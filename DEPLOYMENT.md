# Publish the site

1. GitHub repository https://github.com/hsalarali27/S-Tech-Studio
2. Open https://github.com/hsalarali27/S-Tech-Studio/settings/pages
3. Under Build and deployment select Deploy from a branch, main, /(root), Save.
4. Verify https://hsalarali27.github.io/S-Tech-Studio/ and app policy/support pages.
5. Never place a draft privacy policy in a Play listing. Confirm app-specific contacts, actual SDKs, target audience, processing location and collection/retention.

The root-website repository hsalarali27.github.io is not in use. This is a project Pages site; its base path is /S-Tech-Studio/.
